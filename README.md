House Price Prediction
This project predicts house prices using Linear Regression and the California Housing Dataset

 Project Overview
- Dataset: California Housing (scikit learn)
- Model: Linear Regression
- Evaluation Metrics: Mean Squared Error (MSE), R-squared (R²)
- Visualization: Actual vs Predicted, Residuals, Feature Importance

 Results
- R² Score: ~0.58
- The model explains ~58% of house price variation
- Visual analysis confirms reasonable baseline performance
